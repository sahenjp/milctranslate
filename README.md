# MiL;C Translate

自然文と MiL;C を相互変換する、依存関係なしの小さな試作ツールです。

## 使い方

`index.html` をブラウザで開くだけで動きます。

- 自然文 → MiL;C
- MiL;C → 自然文
- 結果をコピー
- 入力内容を含む共有リンクをコピー
- ライト / ダークモード自動対応

変換は現在ルールベースです。未知の意味を勝手に補完せず、解釈しきれない文は `raw(...)` として残します。

## GitHub Pages

このリポジトリは静的ファイルだけで構成されています。

GitHub の **Settings → Pages** で、`main` ブランチのルートを公開元に選べばそのまま公開できます。

## 構成

```
index.html
.nojekyll
README.md
```

ビルド、パッケージマネージャー、外部 API は不要です。
